# EVDash — releases

Distribuição pública do EVDash para Android/BYD. Este repositório contém somente notas e arquivos de instalação publicados nas Releases. O código-fonte do aplicativo permanece privado.

O app consulta `https://github.com/rrrabadan/evdash-releases/releases/latest/download/latest.json`, confere a integridade e exige a mesma assinatura Android da versão instalada. A instalação automática requer a autorização ADB local do EVDash e veículo parado em P. Após instalar, verifica o AutoStart BYD.

Nenhuma versão foi publicada ainda.
